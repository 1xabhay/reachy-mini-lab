🐣 Reachy Mini Pet

An always-on desk pet. It follows you round the room, listens, answers out loud, and reacts with its body. Nothing leaves your machine.

Install it from the Reachy Mini dashboard, or read the SDK docs to build on it.

Six layers, one job each

Each layer announces what it observes on a bus and knows nothing about the others, so any one runs alone and any combination runs together. Vision on its own is a robot that watches you; add hearing and it knows when it is spoken to; add a mind and it answers.
